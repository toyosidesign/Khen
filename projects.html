What you're actually buying

A design system, not a picture of one.

Anyone can screenshot a landing page. What they can't copy is the system underneath it — the part that makes the template yours in an afternoon instead of a fortnight.

01

One source of truth

Colors, type, spacing, radius and shadow live in @tp/tokens. Change a brand value once and every template and component restyles with it.

02

A real component library

@tp/ui ships typed React components built on those tokens — not copy-pasted markup you have to keep in sync by hand.

03

Figma that matches the code

The same tokens export as Figma variables. Import them and your design file and your codebase stop drifting apart.

04

Source, docs & updates

TypeScript, Tailwind and Next.js source you can read and extend — with written docs, a commercial licence for client work, and updates included.

// change a brand color in ONE place…
tokens/index.ts  ──┐
                   ├─→ tokens.css       → every app root
                   ├─→ config preset    → Tailwind utilities (bg-brand-500…)
                   └─→ figma-variables  → import into Figma
// …and it propagates to code AND design.

Every template on this page is built on it. Re-skinning one for a client is a token edit, not a find-and-replace.
